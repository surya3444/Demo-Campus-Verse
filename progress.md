## Changes Since Last Update (March 25, 2026)

### New Module: Courses / LMS (Module #14)

Complete online learning management system built from scratch:

- Replaced 4-step course wizard with professional tabbed course builder
- Split-panel curriculum editor with tree sidebar (sections, lessons, quizzes)
- Type-specific lesson editors: Video (embed), Document (BlockNote rich text), Live Session (meeting link)
- Quiz editor with inline question cards, MCQ answer selection, category/points
- LMS-style course viewer with curriculum outline and lesson content rendering
- YouTube/Vimeo auto-embed for video lessons
- BlockNote rich text editor component (new shared UI component)
- `contentHtml` field added to lesson schema for document content persistence
- Course visibility controls (organization-wide, branch-specific, private)
- Publish/unpublish flow from builder

### UI Fixes

- Fixed accent color (bright cyan to subtle tint) for dropdown/command hover states across the app
- Instructor picker dropdown no longer shows bright cyan highlight

### Code Cleanup

- Deleted dead code: CourseStepper.tsx, ModulesStep.tsx, LessonsStep.tsx, QuizzesStep.tsx, CourseDetailsStep.tsx
- Removed unused Tiptap packages (replaced with BlockNote)

### Updated Counts

- Web pages: 153 to 174 (+21 pages)

- API controllers: 94 (no change to count, but courses controllers rebuilt)
- Shared schemas: 14 (contentHtml added to courses.schema.ts)
- Test files: 5 to 8 (+dates, generators, pagination util tests)
