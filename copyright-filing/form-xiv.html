ANNEXURE A

Technical Description of the Work

1. Overview

Campus Verse is a multi-tenant, cloud-based Enterprise Resource Planning (ERP) software platform designed for educational institutions including schools, colleges and universities. It is delivered as an integrated suite comprising a backend REST API, three web applications and two cross-platform mobile applications, sharing common type definitions and business logic through internal libraries.

2. Architecture

The work is organised as a pnpm + Turborepo monorepo containing:

  • apps/api — Backend REST API built on Node.js and Express.js, with MongoDB and Redis as primary data stores.
  • apps/web — Institution administrator and staff web portal, built on Next.js 15 (React, App Router).
  • apps/superadmin-web — Super-administrator and marketing/leads portal, built on Next.js 15.
  • apps/mobile-student — Cross-platform (iOS & Android) mobile application for students, built on React Native (Expo).
  • apps/mobile-staff — Cross-platform mobile application for teaching and administrative staff, built on React Native (Expo).
  • packages/shared — Shared TypeScript types, Zod validation schemas, constants and utility functions consumed by the API and web applications.
  • packages/mobile-shared — Shared modules for the two mobile applications.
  • packages/eslint-config — Shared linting configuration.

3. Functional Modules

The platform implements the following original functional modules, each comprising its own data models, business-logic services, controllers and user-interface components:

  • Authentication & Authorisation — JWT-based sessions with token refresh; role-based access control (RBAC) with granular per-module/per-action permissions; tenant- and branch-scoped access control.
  • Organisation & Onboarding — Multi-tenant organisation setup, branch management, feature-gating based on subscription.
  • Admissions Pipeline — A unified 10-stage Kanban pipeline covering Lead capture (new → contacted → interested → followup → visit_scheduled → visited) and Application processing (applied → docs_verified → fee_paid → enrolled), with bidirectional sync between leads and applications.
  • Student Lifecycle — Enrolment, profile, classes, sections, promotion across academic years.
  • Attendance — Daily and period-wise attendance tracking with multiple statuses.
  • Finance — Fees, receipts (auto-generated receipt numbers), transactions, integration with Razorpay payment gateway.
  • Human Resources — Staff records, employee IDs, leave management.
  • Teaching Suite — Timetable slots and entries, lesson plans, assignments, gradebook, "My Classes" and "My Students" views for teachers.
  • Examinations — Exam schedules, marks entry, hall tickets, report card generation, promotion engine.
  • Live Classes — Admin-scheduled live online classes for sections.
  • Transport — Bus routes with Google Maps integration, stops, flat or per-stop pricing, student enrolments.
  • Communications — SMS, email (Resend), in-app notifications.
  • Certificates — Certificate generation and issuance.
  • Dashboards — Role-based dashboards (Owner / Branch Admin / Staff).
  • Super-Admin Portal — Tenant provisioning, marketing leads Kanban, module/feature management.
