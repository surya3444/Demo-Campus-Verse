1. Executive Summary

Campus Verse is an original computer program (literary work) authored as a unified multi-tenant Software-as-a-Service (SaaS) platform that automates academic, financial, administrative and communication workflows for schools, colleges and universities. The work consists of an integrated codebase distributed across five (5) deployable applications and three (3) shared internal libraries, organised as a pnpm + Turborepo monorepo.

8. Multi-Tenancy Model

Each MongoDB document carries a tenantId, set from a verified JWT claim, scoping all queries to the calling tenant. Branch-scoped endpoints additionally require an X-Branch-Id HTTP header, validated against the user's access-scope. Feature availability per tenant is enforced by a requireModule() middleware backed by a 5-minute Redis cache. Institution-type schemas (School, College, University) determine the academic hierarchy: Branch → Class (Grade/Stream/Department) → Section → Students.
